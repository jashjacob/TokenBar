What it does

Countdowns5-hour windows sit larger. Longer windows shrink when the bar fills up.
Your own loginsIf TokenTracker comes back stale or empty, Command Code, OpenCode, Grok, and Cursor can be read directly.
One scriptClone the repo and run install.sh. No Xcode app. No paid Apple account.

Install via command line

git clone https://github.com/jashjacob/TokenBar.git
cd TokenBar
./scripts/install.sh

psst, make sure you have TokenTracker installed.
